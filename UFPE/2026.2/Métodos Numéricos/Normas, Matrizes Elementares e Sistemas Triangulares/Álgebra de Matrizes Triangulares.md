Existem uma série de propriedades muito úteis envolvendo a [[Matriz Inversa|inversa]] e o [[Multiplicação de matrizes|produto]] de [[Definições e propriedades de Matrizes|matrizes]] triangulares, são elas:

1. A inversa de uma triangular superior é uma triangular superior
2. A inversa de uma triangular inferior é uma triangular inferior
3. O produto de triangulares superiores é uma triangular superior
4. O produto de triangulares inferiores é uma triangular inferior
5. A inversa de uma triangular superior unitária é uma triangular superior unitária
6. A inversa de uma triangular inferior unitária é uma triangular inferior unitária
7. O produto de triangulares superiores unitárias é uma triangular superior unitária
8. O produto de triangulares inferiores unitárias é uma triangular inferior unitária
