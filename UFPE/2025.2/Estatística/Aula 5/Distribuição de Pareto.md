Uma outra distribuição muito interessante é a distribuição de Pareto, que modela  [[Variável Aleatória Contínua|variáveis aleatórias contínuas]] que podem representar diversos fenômenos sociais, controle de qualidade, científicos e muito mais e a sua ficha técnica é a seguinte:

| **Característica**                                                                                         | **Valor**                                                                                                                                                      |
| ---------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Intervalo                                                                                                  | $[1,\infty)$                                                                                                                                                   |
| Parâmetros                                                                                                 | $m, \alpha > 0$                                                                                                                                                |
| Função densidade de probabilidade                                                                          | $f(x) = \dfrac{\alpha\cdot m^\alpha}{x^{\alpha + 1}}$                                                                                                          |
| [[Função de distribuição acumulada para variáveis aleatórias contínuas\|função de distribuição acumulada]] | $F(x) = 1 - \dfrac{m^\alpha}{x^{\alpha}}$, $x \geq m$                                                                                                          |
| Notação                                                                                                    | $X\sim \text{Pareto}(m, \alpha)$ ou $X\sim \text{Pr}(m, \alpha)$                                                                                               |
| Modelo                                                                                                     | Frequentemente usada para modelar **fenômenos de distribuição desigual**, onde uma pequena quantidade de elementos tem a maior parte de algum recurso ou valor |
