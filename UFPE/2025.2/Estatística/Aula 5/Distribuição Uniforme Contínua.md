Assim como temos a [[Distribuição Uniforme discreta]], podemos também definí-la para uma [[Variável Aleatória Contínua]], modelando o mesmo tipo de situação, onde qualquer valor dentro de um intervalo $[a,b]$ tem a mesma probabilidade, nesse caso, temos a seguinte ficha técnica:

| **Característica**                                                                                         | **Valor**                                                                                     |
| ---------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| Intervalo                                                                                                  | $[a,b]$                                                                                       |
| Parâmetros                                                                                                 | $a$, $b$                                                                                      |
| Função densidade de probabilidade                                                                          | $f(x) = \dfrac{1}{b-a}$                                                                       |
| [[Função de distribuição acumulada para variáveis aleatórias contínuas\|função de distribuição acumulada]] | $F(x) = \dfrac{x-a}{b-a}$                                                                     |
| Notação                                                                                                    | $X\sim \text{Uniforme}(a,b)$ ou $X\sim \text{U}(a,b)$                                         |
| Modelo                                                                                                     | Espaço amostral onde qualquer valor dentro de um intervalo $[a,b]$ tem a mesma probabilidade. |
