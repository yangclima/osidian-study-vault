Partindo de uma complexa tabela de dados é possível, usando uma tabela de frequência , simplificar muito a visualização das informações, é possível simplificar ainda mais estes dados utilizando um que chamamos de **medidas de posição central**, são elas: Média, moda e mediana.

para conjuntos de dados não agrupados a média aritmética pode ser definida da seguinte maneira:

$$
\int_{-L/2}^{l/2} \dfrac{dx}{(x^2 + y^2)^{3/2}}
$$
