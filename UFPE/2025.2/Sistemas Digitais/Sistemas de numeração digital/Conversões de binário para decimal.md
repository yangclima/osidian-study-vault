Pra converter do [[Sistemas de numeração digital|sistema de numeração]] binário para o decimal precisamos entender que cada posição, equivale a uma potência de 2, da esquerda para a direita, temos $2^0$, $2^1$, $2^2$, $2^3$, $\cdots$, $2^n$, e pode ser $0$ ou $1$, dessa forma, para converter de binário para decimal, precisamos multiplicar o número em cada posição pela potência de $2$ que a posição representa.

Dessa forma, um número como $10110$ será convertido a partir da seguinte operação: $0\cdot2^0 + 1\cdot2^1 + 1\cdot2^2 + 0\cdot2^3 + 1\cdot2^4 = 22$. Tendo em vista que o sistema decimal é o que usamos cotidianamente nas operações matemáticas, esse mesmo método funciona para conversão a partir de qualquer sistema de numeração, basta substituir o $2$ pela base do sistema do qual se quer converter.
