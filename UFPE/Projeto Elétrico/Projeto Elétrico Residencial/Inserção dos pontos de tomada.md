Após a [[Inserção de Pontos de Iluminação]] o próximo passo é  planejar e definir os nossos pontos de tomada, para tal função a [[NBR5410.pdf|NBR 5410]] específica no item `9.5.2.2` algumas diretrizes para as quantidades de pontos de tomada e suas potências.

Sendo, quanto ao número e potência dos pontos de tomada:

| Cômodo                                                            | Número de pontos                                                                                                         | Potências                                                             |
| ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------- |
| Cozinhas, copas, áreas de serviço, lavanderia ou áreas correlatas | Um ponto de tomada a cada $3,5m$, ou fração, de perímetro, com pelo menos dois pontos acima da bancada da pia.           | $600\text{VA}$ por ponto até 3 pontos e $100\text{VA}$ para os demais |
| Banheiros                                                         | Pelo menos um ponto, próximo ao lavatório                                                                                | $600\text{VA}$ por ponto até 3 pontos e $100\text{VA}$ para os demais |
| Varandas                                                          | Pelo menos um ponto                                                                                                      | No mínimo $100\text{VA}$ para cada ponto de tomada                    |
| Salas e dormitórios                                               | Um ponto a cada $5m$, ou fração, de perímetro, tão uniformemente espaçados quanto possível                               | No mínimo $100\text{VA}$ para cada ponto de tomada                    |
| Outros                                                            | Um ponto se a área for inferior a $6m^2$ e um ponto a cada $5m$, ou fração, de perímetro para uma área superior a $6m^2$ | No mínimo $100\text{VA}$ para cada ponto de tomada                    |

OBS: Esses são os pontos de Tomadas de Uso Geral (TUG's), devem ser somados a esses os pontos de Tomadas de Uso Específico (TUE's), pensados pontualmente para equipamentos elétricos específicos, além disso, para áreas abertas e piscinas, há itens específicos ma normas para isso.

Um caso muito comum de TUE é a tomada para refrigeração, para dimensionar o ar-condicionado para $3,00 m$ de altura, consideramos como quantidade base $600\ \ \text{BTU/}m^2$ para cômodos sem janela e $800\ \ \text{BTU/}m^2$ para cômodos com janela por pessoa que utiliza o cômodo, ainda é comum somar $600/800 \ \text{BTU}/m^2$ à quantidade para cada equipamento eletrônico no quarto para essas TUE, usar pontos de tomadas não plugáveis e seguir as seguintes orientações ([[DIS-NOR-030-REV07.pdf|DIS-NOR-030]]) para a potência desses equipamentos:

Quanto ao posicionamento do quadro de distribuição, este geralmente fica a uma altura de trabalho de $1.5m$ e idealmente fora de locais de alta circulação, o mais próximo possível a medição.

Quanto a distribuição e divisão dos circuitos, distribuímos os circuitos usando 1100W por circuito de iluminação e 1200W por circuito de tomadas, setorizando os circuitos começando pelas TUG's e depois as TUE's.
