
| Comando                   | Função                                                                      |
| ------------------------- | --------------------------------------------------------------------------- |
| `DI` + `Enter`            | Medir distância entre dois pontos                                           |
| `SC` + `Enter`            | Aplicar um fator de escala a um objeto selecionado                          |
| `OP` + `Enter`            | Abrir as opções do projeto                                                  |
| `ED` + `Enter`            | Editar Texto                                                                |
| `PL` + `Enter`            | Criar Polyline                                                              |
| `BE` + `Enter`            | Editar bloco                                                                |
| `PURGE` + `Enter`         | Exclui Layers e blocos que estão vazios                                     |
| `LAYDEL` + `Enter`        | Exclui Layers mesmo as que tem itens internos                               |
| `MA`+ `Enter`             | Corresponder propriedades                                                   |
| `SE` + `Enter`            | Menu de Snap                                                                |
| `MO` + `Enter`            | Abre as propriedades do objeto selecionado                                  |
| `REFEDIT` + `Enter`       | Permite editar um bloco sem abrí-lo                                         |
| `REFEDIT` + `Enter`       | Salva as edições feitas em `REFEDIT`                                        |
| `FIND`+`Enter`            | Permite procurar e substituir textos                                        |
| `SELECTSIMILAR` + `Enter` | Seleciona automaticamente todos os objetos similares ao atual               |
| `F` + `Enter`             | Fillet - Criar uma transição sútil entre duas linhas com ângulos diferentes |
| `EX` + ``Enter``          | Extender linha                                                              |
