Um predicado, a nossa segunda estrutura do contexto da matemática discreta, pode ser entendido como uma [[Proposições|proposição]] cuja validade depende de um conjunto de variáveis. Por exemplo, a afirmação "$n$ é um número primo" só pode ser avaliada como verdadeira ou falsa quando determinamos o valor de $n$, a partir do momento que esse valor é especificado, digamos $n = 2$, o predicado se torna a proposição "$2$ é um número primo", avaliada como verdadeira.

Tal qual as demais proposições, os predicados podem ser representados através de uma letra, além disso, é comum usar uma notação semelhante a usada para funções para representar predicados preenchido com valores específicos para as variáveis, por exemplo, podemos usar o $P$ para nomear o predicado citado anteriormente:

$$P ::= \text{"n é um número primo"} $$

Então, $P(5)$ equivale a proposição "5 é um número primo" e $P(9)$ equivale a "9 é um número primo", de modo que $P(5)$ é verdadeira e $P(9)$ é falsa.

> OBS: Deve-se tomar muito cuidado para não confundir essa notação, onde $P(n)$ representa uma proposição e é verdadeira ou falsa, enquanto uma função $P(n)$ representa um valor propriamente.
