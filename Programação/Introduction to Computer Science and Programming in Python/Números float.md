O computador armazena números de ponto flutuante de maneira diferente dos números inteiros, para que seja possível armazenar valores ainda maiores do que com a representação convencional. A forma de representação usada é através de um par de números $(a,b)$ que representam uma número de ponto flutuante qualquer $c$, onde $c = a \cdot 2^b$, o que, apesar de permitir um armazenamento muito maior nos trás como consequência um certa imprecisão na representação de alguns números (Como $0.1$), já que só podemo0s considerar um número finito de ***Algarismos significativos**.
