No segundo dia, o tema abordado foi, resumidamente, o ambiente de desenvolvimento e as ferramentas básicas desse ambiente: O Git, o GitHub e a IDE. 
# Git *versus* GitHub
Muitos se confundem ao tentar explicar a diferença entre esses dois, mas, resumidamente, o Git é um software de controle de versão enquanto o GitHub é tanto um repositório de código online, quanto uma rede social voltada a programadores. A analogia usada pelo Felipe para explicar isso é a comparação entre um vídeo.mp4 arquivado no seu computador (O Git) *versus* o YouTube (O GitHub). Ao criar uma conta no GitHub, passamos a poder criar inúmeros repositórios públicos ou privados, pode ser interessante, ao criar um repositório de um projeto no GitHub, levar em conta o SEO (Search Engine Optimization), utilizando tanto no título (Que preferivelmente deve ser curto e memorável) quando na descrição do seu projeto bem como no seu README.md palavras chave que possam facilitar que pessoas interessadas no tema abordado por seu projeto, o encontrem. 
# Ambiente de Desenvolvimento
O ambiente de desenvolvimento é basicamente, o conjunto de feerramentas que você utilizará para desenvolver o seu projeto e sua escolha e construção aborda dois principais fatores: **A função e a estética**. A função está relacionada as facilidades que seu ambiente pode te prover no desenvolvimento, enquanto a estética está relacionada a aparência desse ambiente. Como existem milhões de maneiras de configurar um ambiente de desenvolvimento, para facilitar a integração das ideias, o curso.dev utiliza o mais simples possível: **O codespaces**.
# CodeSpaces
O codespaces é um ambiente de desenvolvimento em nuvem integrado ao GitHub que permite iniciar uma IDE online, diretamente no seu repositório, com diversas ferramentas integradas e já prontas, bem como um terminal linux integrado, entre as ferramentas estão o NVM, Node, Docker, Git e muito mais
