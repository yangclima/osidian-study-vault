| **Atalho**           | **Funcionalidade**                                                             |
| -------------------- | ------------------------------------------------------------------------------ |

| `Ctrl + /`           | Comentar/Descomentar uma linha                                                 |
| `Ctrl + Shift + F10` | Executar o arquivo atual                                                       |
